# 🚀 AI Model Selector (Machine Learning)

This project is a Machine Learning Model Selector that helps identify the best-performing algorithm for a given dataset. It supports both **classification** and **regression** tasks and allows users to experiment with different datasets to compare model performance.

---

## 🔍 Project Overview

Choosing the right model is one of the most important steps in machine learning. This project simplifies that process by:

- Running multiple ML models on the same dataset  
- Comparing their performance  
- Helping users select the most suitable model  

The dataset included is for demonstration purposes, and users can replace it with their own dataset.
